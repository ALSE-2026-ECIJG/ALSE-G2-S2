**Estudiante:** Andres Felipe Pinilla Velandia  
**Institucion:** Escuela Colombiana de Ingenieria Julio Garavito

Proyecto en C++ con tres ejercicios de programacion orientada a objetos:
1. Gestion basica de biblioteca.
2. Sistema de alquiler de autos y bicicletas.
3. Carrito de compras e historial de compras.

## Requisitos
- CMake 3.10 o superior
- Compilador compatible con C++17

## Compilar
Desde la carpeta principal:
```bash
cmake -S . -B build
cmake --build build
```
Los ejecutables se generan dentro de la carpeta `build` (la ruta exacta depende del sistema operativo y generador).

## Notas
Los programas usan clases, atributos privados, metodos sencillos y menus de consola. El sistema de alquiler utiliza herencia y metodos virtuales.
